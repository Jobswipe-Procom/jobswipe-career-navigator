## 🎯 Overview & Objectives

**JobSwipe AI** was born from a simple observation: modern job searching has become a long, repetitive, and discouraging process for young talents. Traditional platforms often overwhelm candidates with irrelevant offers.

### Problem Statement
How can we simplify job access for young professionals while significantly increasing application relevance?

### The Solution
A mobile application that leverages Artificial Intelligence to create **semantic matching**. Similar to modern dating apps, users simply **swipe right** to apply or **swipe left** to ignore.

---

## ⚙️ Methodologies

We adopted a modern development approach to ensure flexibility, speed, and product robustness.

- **Project Management:** **Agile (Scrum)** methodology with two-week sprints to integrate user feedback continuously.
- **Technical Architecture:**
    - **Frontend:** Flutter (Cross-platform iOS/Android).
    - **AI Engine:** Semantic analysis via LLM APIs (Python-based backend).
    - **Workflow:** `Job Data` ➔ `Semantic Matching` ➔ `Swipe Interface`.
